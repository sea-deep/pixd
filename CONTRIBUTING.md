# Contributing to Discord Bot Template

First off, thank you for considering contributing to this template! It's people like you that make this tool great for everyone.

## 🤝 How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an Issue in the GitHub repository. Ensure you include:
- Your Node.js version
- Your Discord.js version
- A clear, step-by-step description of how to reproduce the bug
- Any relevant error logs

### Suggesting Enhancements
Have an idea to make this template better?
- Head over to the **Discussions** tab to share your thoughts before writing any code. We'd love to hear your ideas!
- Once the idea is validated, you can open an Issue to track its progress.

### Submitting Pull Requests
1. **Fork the repo** and create your branch from `main`.
2. **Write your code** ensuring it follows the existing TypeScript styles and structure.
3. **Test your code** by running the bot locally in development mode (`npm run dev`) and verifying your changes work as intended without breaking existing Hybrid Commands or Handlers.
4. **Submit a Pull Request** with a clear title and description of your changes.

## 📜 Coding Guidelines
- **Type Safety**: Please ensure all new additions are strictly typed. Do not use `any` unless absolutely necessary.
- **Modularity**: If you are adding a new core feature, try to keep it isolated within its own service or handler class.
- **Documentation**: If your PR introduces a new architecture pattern (like a new UI component handler), please note that the Wiki will also need to be updated.

We appreciate your time and effort!
